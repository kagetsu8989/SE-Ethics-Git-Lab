ЛАБОРАТОРИЙН АЖИЛ №1
Хөгжүүлэлтийн орчин байгуулах ба Git ашиглах

1. Git гэж юу вэ?

Git нь програмын эх код болон файлуудад хийгдсэн өөрчлөлтүүдийг
хянах, хадгалах зориулалттай хувилбарын удирдлагын систем юм.
Git-ийн тусламжтайгаар өмнөх хувилбар руу буцах, өөрчлөлтийн
түүхийг харах болон багаар хамтран ажиллах боломжтой.

2. Repository гэж юу вэ?

Repository нь төслийн файлууд болон тэдгээрт хийгдсэн
өөрчлөлтийн түүхийг хадгалдаг Git-ийн сан юм.
Repository нь local болон remote хэлбэртэй байж болно.

3. Commit гэж юу вэ?

Commit нь тухайн үеийн төслийн өөрчлөлтүүдийг Git-ийн
түүхэнд хадгалсан хувилбар юм. Commit бүр өөрийн hash
дугаар болон тайлбар буюу commit message-тэй байдаг.

4. Branch ямар зориулалттай вэ?

Branch нь үндсэн кодод шууд нөлөөлөхгүйгээр шинэ боломж,
туршилт эсвэл өөрчлөлт дээр тусдаа ажиллах боломж олгодог.
Ажил дууссаны дараа branch-ийн өөрчлөлтийг үндсэн branch-тай
нэгтгэж болно.

5. Git ашиглах нь багийн ажилд ямар давуу талтай вэ?

Git ашигласнаар багийн гишүүд нэг төсөл дээр зэрэг ажиллах,
өөрсдийн өөрчлөлтийг тусдаа branch дээр хийх, өөрчлөлтийн
түүхийг харах, кодыг хэн хэзээ өөрчилснийг тодорхойлох,
зөрчил гарсан үед түүнийг удирдах боломжтой.

6. Git ашиглах нь мэргэжлийн шударга байдалтай ямар холбоотой вэ?

Git-ийн commit history нь кодод хэн, хэзээ, ямар өөрчлөлт
хийснийг харуулдаг. Иймээс бусдын хийсэн ажлыг өөрийн нэрээр
commit хийхээс зайлсхийх, хийсэн хувь нэмрээ үнэн зөв бүртгэх
нь мэргэжлийн шударга байдлыг хангахад чухал ач холбогдолтой.

7. Лабораторийн явцад ямар хүндрэл гарсан бэ?

Git-ийн branch, staging area болон commit-ийн ялгааг эхэндээ
ойлгоход бага зэрэг хүндрэлтэй байсан. Мөн local repository-г
GitHub remote repository-той холбох үйлдлийг сурах шаардлагатай
байсан.

8. Түүнийг хэрхэн шийдсэн бэ?

git status, git branch, git log зэрэг командуудыг ашиглан
repository-ийн төлөвийг тогтмол шалгаж, Git-ийн үйл ажиллагааг
алхам бүрээр туршиж ойлгосон. Мөн GitHub repository-г remote
repository болгон тохируулж push хийх замаар асуудлыг шийдсэн.
